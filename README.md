# 地狱之下 - 文档

完整PDF在[发行版](https://gitcode.com/CrossDark/UnderHellDocs/releases/)

[地狱之下](https://gitcode.com/CrossDark/UnderHell) 项目的 Typst 文档源码,使用架空世界模板渲染。

## 文件

| 文件 | 说明 |
|------|------|
| `地狱之下.typ` | 全量单页入口(PDF 与网页 `/index.html`) |
| `配置.typ` | 站点配置(网页模板、站内导航链接、页面清单) |
| `内容/<编号-名称>/index.typ` | 独立页入口(网页多页站点的一页) |
| `内容/<编号-名称>/正文.typ` | 该页正文(自带 `#import "/模板/lib.typ": *`) |
| `元素系统.csv` | 元素系统数据(宽表:首行=系统名,首列=元素 id) |
| `Makefile` | 编译脚本(普通/打印/小屏/元素系统版/网页) |
| `web_post.py` | 网页后处理(抽外部样式、跨页元素链接) |

## 编译

```bash
# 普通版
make all

# 打印版 / 小屏版
make print
make screen

# 指定元素系统
make 元素系统 元素系统名=academic

# 网页版:完整单页 dist/index.html + 各独立页 dist/<编号-名称>/index.html
make web
```

## 网页多页站点

`内容/` 下每个 `<编号-名称>/index.typ` 是一个独立网页;`正文.typ` 是纯内容,
必须自己 `#import "/模板/lib.typ": *`(`include` 不继承父文件作用域)。

页面用 `配置.typ` 的 `网页模板`:

```typst
#import "../../配置.typ": 网页模板
#show: 网页模板.with(页标题: "怪动植物")
#include "正文.typ"
```

- 站内链接与字体一律绝对路径(`/01-世界纲要/`、`/webfonts/`),支持多级路由
  (`内容/05-特殊能力/01-仙术/`)。
- 各页共享抽出的外部样式 `dist/assets/underhell.css`。
- 元素定义在别页时,`web_post.py` 把该页的"未定义"元素重写成指向定义所在页的链接。
- `配置.typ` 的 `页面` 清单决定导航与总览页;空内容不建 `index.typ` 即不出页。

## 元素系统

元素系统通过 `#元素("ID")` 在文档中引用核心概念。**普通系统直接返回 ID 本身**,其他系统(别名、academic)从 `元素系统.csv` 宽表中查找。

CSV 格式:首行为各元素系统名(不含普通),首列是元素 id,单元格为对应名词(空则回退到普通)。

```csv
id,别名,academic
怪物,,
怪动物,白色怪物,
怪动植物,黑白怪物,
超级系统,,生物能量超级系统
嗜血仙子,黑白仙女,
水仙子,水仙女,
```

**只要文档中使用了 `#元素("xxx")`,就必须将 `xxx` 写入 CSV id 列。** 元素文本在渲染时自动标红(深红)并使用标题字体。

- `#元素(id)`:引用某元素,渲染当前系统深红名词;该元素在文档中有标题时自动成为跳转链接。
- `#设定元素(id, level: none)`:普通模式为深红文本;传入 `level` 即为标题(`= 标题 <id>`,`@id` 可交叉引用)——
  `#设定元素(level: 2)[伪神]`。文档中的章节标题均用此形式定义。
- `#评论(正文)`:标题字体、灰色注释,`--input 隐藏评论=true` 编译时隐藏。

未定义元素(被引用但暂无定义小节):PDF 编译给出 warning;HTML 输出(`--features html --input html=true`)渲染悬停弹窗"未定义"。

可运行 `程序/元素工具/元素工具.py` 自动补全编码/改名元素,详见 [程序/元素工具/README.md](../程序/元素工具/README.md)。

## 字体

通过 `lang: "zh"` 加载中文配置(`模板/languages/zh.toml`)。字体配置:

- `header`:段宁毛笔小楷(标题 + 元素默认)
- `body`:霞鹜文楷等宽(正文)
- `italic`:等距更纱黑体 SC(斜体)
